# College Management System

A simple Python-based College Management System designed to manage basic college activities and student information.

## Features

* Student Management
* Faculty Management
* Course Management
* Attendance Management
* Marks Management
* Fees Management
* Timetable Management

## Technologies Used

* Python
* Basic Python concepts
* Lists, functions, loops, conditions, and user input

## How to Run

1. Download or clone the repository.
2. Open the project in Python or VS Code.
3. Run the `main.py` file.
4. Follow the options displayed in the menu.
  Project Purpose

This project was created to practice Python programming and understand how basic management systems can be developed using simple programming concepts.
